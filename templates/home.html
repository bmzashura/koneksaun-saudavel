Cara Kerja

Arsitektur

Setiap perangkat yang terhubung ke jaringan akan menggunakan DNS server untuk mengubah nama domain menjadi alamat IP. Koneksaun Saudavel bekerja sebagai DNS proxy yang mencegat setiap permintaan dan memverifikasi domain terhadap blocklist lokal. Jika domain ada di daftar blokir, query diblokir. Jika tidak, permintaan diteruskan ke upstream DNS server.

  • Client → Kirim query DNS
  • CoreDNS → Terima query di port 53
  • DNS Filter → Cek domain terhadap blocklist
  • Block → NXDOMAIN untuk domain terblokir
  • Forward → Limpahkan ke upstream DNS
Blocklist

Koleksi domain dikurasi dari berbagai sumber terpercaya:

  • Ads & Trackers — 241,828 domains dari AdGuard SDNSFilter
  • Adult Content — 500,282 domains dari BlocklistProject
  • Gambling — 2,500 domains dari blocklistproject

Total: 744,610 domains terus diperbarui untuk perlindungan maksimal.

Cara Melaporkan Domain

Langkah Pelaporan
1
Login ke Dashboard

Masuk dengan akun yang sudah terdaftar di halaman login.

2
Buka Halaman Report

Klik menu "Report" di sidebar dashboard untuk membuka form pelaporan.

3
Isi Form

Masukkan domain yang ingin diblokir, pilih kategori, dan jelaskan alasannya.

4
Submit & Tunggu Review

Setelahsubmit, tim admin akan meninjau laporan dan menambahkan ke blocklist jika valid.

Informasi Penting

Berikut beberapa hal yang perlu diketahui sebelum melaporkan domain:

  • Domain akan direview oleh tim admin dalam 1x24 jam
  • Pastikan domain benar-benar termasuk kategori yang dipilih
  • Report yang tidak valid atau tidak Relevan tidak akan diproses
  • Semua user bisa Submit report — tidak terbatas pada admin
  • Anda dapat melihat status report di halaman "Reports"
Tips:

Sebelum melaporkan, coba visit domain terlebih dahulu untuk memastikan kontennya memang tidak pantas atau melanggar kebijakan penggunaan internet yang bertanggung jawab.

Tips Internet Aman & Bertanggung Jawab

Awasi Anak-Anak
Gunakan tools parental control dan tetap awasi aktivitas online anak-anak. Komunikasi terbuka tentang risiko internet juga sangat penting.
Gunakan Password Kuat
Buat password yang unik untuk setiap akun. Gunakan minimal 12 karakter dengan kombinasi huruf, angka, dan simbol.
Hindari Situs Tidak Aman
Periksa URL sebelum memasukkan informasi sensitif. Pastikan ada HTTPS dan simbol gembok di address bar browser.
Batasi Waktu Layar
Tetapkan batas waktu penggunaan internet untuk diri sendiri dan keluarga. Gunakan fitur screen time di masing-masing perangkat.
