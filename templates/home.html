Cara Kerja

Arsitektur

Setiap perangkat yang terhubung ke jaringan menggunakan server DNS untuk menerjemahkan nama domain ke alamat IP. Koneksaun Saudavel bekerja sebagai proxy DNS yang intercepted setiap permintaan dan memverifikasi domain terhadap daftar blokir lokal. Jika domain ada di daftar blokir, query akan diblokir. Jika tidak, permintaan akan diteruskan ke server DNS upstream.

  • Klien → Kirim query DNS
  • DNS Server → Terima query di port 53
  • Filter DNS → Periksa domain terhadap daftar blokir
  • Blokir → NXDOMAIN untuk domain terblokir
  • Teruskan → Teruskan ke DNS upstream

Cara Melaporkan Domain

Langkah-langkah Pelaporan
1
Login ke Dashboard

Masuk dengan akun terdaftar Anda di halaman login.

2
Buka Halaman Laporan

Klik menu "Laporan" di sidebar dashboard untuk membuka formulir pelaporan.

3
Isi Formulir

Masukkan domain yang ingin Anda blokir, pilih kategori, dan jelaskan alasan Anda.

4
Kirim & Tunggu Tinjauan

Setelah mengirim, tim admin akan meninjau laporan dan menambahkannya ke daftar blokir jika valid.

Informasi Penting

Berikut beberapa hal yang perlu diketahui sebelum melaporkan domain:

  • Domain akan ditinjau oleh tim admin dalam 24 jam
  • Pastikan domain tersebut memang termasuk dalam kategori yang dipilih
  • Laporan yang tidak valid atau tidak relevan tidak akan diproses
  • Semua pengguna dapat mengirim laporan — tidak terbatas pada admin
  • Anda dapat memeriksa status laporan di halaman "Laporan"
Tips:

Sebelum melaporkan, coba kunjungi domain terlebih dahulu untuk memastikan kontennya memang tidak pantas atau melanggar kebijakan penggunaan internet yang bertanggung jawab.

Tips Internet Aman & Bertanggung Jawab

Pantau Anak-anak
Gunakan alat kontrol orang tua dan pantau aktivitas online anak-anak. Komunikasi terbuka tentang risiko internet juga sangat penting.
Gunakan Kata Sandi Kuat
Buat kata sandi unik untuk setiap akun. Gunakan minimal 12 karakter dengan campuran huruf, angka, dan simbol.
Hindari Situs Tidak Aman
Periksa URL sebelum memasukkan informasi sensitif. Pastikan ada HTTPS dan ikon gembok di address bar browser Anda.
Batasi Waktu Layar
Tetapkan batas waktu penggunaan internet untuk diri sendiri dan keluarga. Gunakan fitur waktu layar di setiap perangkat.
