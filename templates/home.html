How It Works

Architecture

Every device connected to the network uses a DNS server to translate domain names into IP addresses. Koneksaun Saudavel works as a DNS proxy that intercepts every request and verifies the domain against a local blocklist. If the domain is on the blocklist, the query is blocked. Otherwise, the request is forwarded to the upstream DNS server.

  • Client → Send DNS query
  • CoreDNS → Receive query on port 53
  • DNS Filter → Check domain against blocklist
  • Block → NXDOMAIN for blocked domains
  • Forward → Forward to upstream DNS
